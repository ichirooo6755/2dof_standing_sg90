# 浅い傾きからの復帰と上段停止の調査

2026-11-11。対象は XIAO nRF54L15 Sense、USB serial `6E0C2EEC`、下段 D0・上段 D1。書き込み版は `sg90-nrf54-9`。

## 復帰の条件

- 傾きの開始条件を45°から15°へ変更した。
- 生の加速度・角速度が静止条件を連続300ms満たすと、既存の起き上がり方策を開始する。途中で動けば300msを数え直す。
- 待機中に8°未満へ戻れば待機を取り消す。復帰してアームの指令も中央へ戻れば、次の転倒を監視する。
- 重力ベクトルで判定するため、前後・左右・斜めを同じ条件で扱う。姿勢推定と50Hzの制御周期による検出・出力の遅れは別にある。
- 静止の条件は角速度0.2rad/s未満、加速度0.9〜1.1g、加速度の変化が0.04g未満。手で保持して細かく揺らすと静止時間が延びる。
- 下段中央1500µs・上段中央1464µsと既存の学習済み方策は維持した。SG90には軸角度の読み戻しがないため、指令値は実角度を意味しない。

## 確認できた不具合と修正

前版の通常制御は、推論処理と独立に「前回から20ms経過したらパルスを出す」構造だった。ログに最長約35msの出力間隔があった。ポリシーの20ms周期でパルスを先に出し、次にセンサー処理・推論を進める構造へ変更した。

また、中央保持から自動運転へ切り替えるとき、直前のパルス位置に関係なく新しく20ms待っていた。port8の最大間隔は39148µs。port9は直前の保持パルスから次の20ms期限を引き継ぎ、切り替え時のシリアル通知も送信バッファに空きがある場合だけ出す。

これらの周期の問題が、上段の約90°固定を起こしたという因果関係は確認できていない。

## 上段の停止について確認できたこと

- `output/servo_center/stuck_90/before_any_reset.json`：上段が曲がったままという観察時に、フレーム13834から14119へ進んでいた。mode4、指令1500/1464µs、ターゲット角0、台座約2°。この記録ではマイコン全体は停止していない。
- その後、書き込みだけでは戻らない事例があり、使用者の電源入れ直しで戻った。ただしマイコンとサーボを同時に再起動しているため、どちらの状態が解消されたのかは未確定。
- port6の確認用保持中には、マイコン端子で上段約1461〜1466µsのパルスを読めた。サーボ側コネクタの電圧・波形を測った記録ではない。
- port8の150秒の記録では、フレーム3741から11383までmode4で継続。端子の論理レベル不一致は0/0。最大のソフト計測パルス誤差は下段22µs・上段78µs。上段が90°固定した場面の再現記録ではない。
- UARTとD0/D1の物理ピン割り当てに直接の重複はなかった。

現時点で、サーボ内部・配線・電源・マイコン出力のどれが原因かは確定していない。保持トルクがあるという使用者の観察と、指令値・ループ進行が正常という記録を両方扱う。

## 再発時に残す記録

`tools/standing_monitor.py` は `state`、`gate`、`pwm`、`health`、`config` だけを毎秒1件ずつ問い合わせ、動作・停止・再起動の指令は送らない。

```sh
python3 -u tools/standing_monitor.py --seconds 120 --out output/servo_center/freeze_reproduction
```

`pwm` は、指令値・最後に実際に送出した設定値・ソフト上のHIGH時間・出力周期・端子論理レベル不一致数を返す。オシロスコープによるサーボ端での測定ではない。`health` は推論・ループの最大時間と起動時のRESETREAS生値を返す。

再発中に記録を取ってから、サーボへの給電を変えずPWMを停止・中央指令を再送し、次にマイコンだけを再起動する。`restart` はPWMを停止してMCUをリセットする診断用コマンドであり、サーボ電源の切り替えは行わない。これでも残る場合は、マイコンの稼働を保ったサーボ単体の電源再投入と比較する。各段階の実角度は使用者の観察が必要で、ログだけで復帰したとは判定しない。

## 検証範囲

- ネイティブチェック：8方向×15/20/30/45/90/135/180°の56姿勢で300ms待機、浅すぎる姿勢の除外、8°未満への戻し、再転倒、揺れによる時間リセットを確認した。
- パルス生成チェック：中央値、繰り返し、端点、停止・再接続、時計の周回、端子不一致の検出、保持から制御へ切り替える位相の引き継ぎを確認した。
- Arduino CLIのビルドとCMSIS-DAPによる書き込みが成功した。flash64364 bytes / static RAM7660 bytes。
- 最終版の実機ログは `output/servo_center/shallow_freeze_port9/` に保存する。浅い傾きから実際に起き上がれたか、上段停止が解消したかは使用者の観察と別に報告する。
